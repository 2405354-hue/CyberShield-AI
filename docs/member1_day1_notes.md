## What I Learned Today

### Cyber Security
Cyber Security protects computers, networks, and data from unauthorized access and cyber attacks.

### Intrusion
An intrusion is an unauthorized attempt to access a computer system or network.

### Intrusion Detection System (IDS)
An IDS monitors network traffic and detects suspicious or malicious activities.

### Types of IDS

- Network IDS (NIDS): Monitors the entire network.
- Host IDS (HIDS): Monitors a single computer.

### Types of Attacks

- DoS (Denial of Service)
- DDoS (Distributed Denial of Service)
- Brute Force Attack
- Port Scanning

### Difference between IDS and IPS

IDS detects attacks and alerts the administrator.

IPS detects attacks and automatically blocks or prevents them.
